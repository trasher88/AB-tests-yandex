## Структура проекта:
1. Приоритизация гипотез:
    - ICE-анализ;
    - RICE-анализ;
    - сравнение ICE и RICE.
2. Анализ A/B-теста:
    - подготовка данных;
    - кумулятивная выручка;
    - кумулятивный средний чек;
    - относительное изменение среднего чека;
    - кумулятивная конверсия;
    - относительное изменение конверсии;
    - количество заказов на пользователя;
    - перцентили и границы аномалий (заказы);
    - стоимость заказов;
    - перцентили и границы аномалий (выручка).
3. Статистический анализ
4. Выводы

## Методы и подходы:
- Приоритизация гипотез:
    - ICE (Impact, Confidence, Efforts) - быстрая оценка гипотез по соотношению "эффект/затраты";
    - RICE (Reach, Impact, Confidence, Efforts) — расширенная версия ICE с учетом охвата пользователей;
    - сравнительный анализ фреймворков — выявление влияния метрики Reach на итоговые приоритеты.
- Анализ A/B теста:
    - кумулятивный анализ — построение метрик нарастающим итогом для оценки динамики;
    - визуализация трендов — графики выручки, конверсии, среднего чека по группам;
    - относительные изменения — сравнение группы "B" относительно "A" в динамике;
    - обнаружение аномалий — перцентильный анализ для выбросов по заказам и пользователям;
    - статистическая проверка гипотез — t-тест, z-тест, χ²-тест;
    - анализ чувствительности — сравнение результатов на "сырых" и "очищенных" данных.

## В ходе проекта решил следующие задачи:
- Приоритизация гипотез:
    - провел приоритизацию 9 гипотез по фреймворку ICE;
    - провел приоритизацию по фреймворку RICE;
    - выявил критические различия между подходами:
      -	ICE — максимизация ROI на единицу затрат;
      -	RICE — максимизация общего бизнес-эффекта с учетом масштабирования
  -	описал практические рекомендации по выбору гипотез для реализации.
- Анализ A/B теста:
    - построил 6 ключевых визуализаций:
      -	кумулятивная выручка;
      -	кумулятивный средний чек;
      -	относительное изменение среднего чека;
      -	кумулятивная конверсия;
      -	относительное изменение конверсии;
      -	точечные графики заказов и стоимостей.
  - выявил аномальных пользователей (95-й и 99-й перцентили);
  - выявлил аномальные заказы (95-й и 99-й перцентили);
  - провел статистическую проверку по 4 сценариям:
      - конверсия (сырые данные);
      - средний чек (сырые данные);
      - конверсия (очищенные данные);
      - средний чек (очищенные данные).
 - выполнил очистку данных от аномалий;
 - сформулировал обоснованное бизнес-решение с тремя альтернативами.
